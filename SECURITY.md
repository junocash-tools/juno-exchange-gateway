# Security policy

## Supported versions

Security fixes are applied to the latest release and the default branch. Upgrade to a fixed release promptly; older releases are not maintained indefinitely.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/junocash-tools/juno-exchange-gateway/security/advisories/new). Do not open a public issue.

Include the affected version or commit, impact, reproduction steps, and suggested mitigation when available. Never include seeds, spending keys, real UFVKs, credentials, or customer data.

We will acknowledge the report, investigate it, coordinate a fix and disclosure, and credit reporters who request attribution. Avoid accessing data that is not yours or disrupting production systems.
